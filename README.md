# Resonance Android

Jetpack Compose ile yazılmış yerel Android müzik oynatıcı prototipi.

Kaynaklar `resonance-src.tar.xz` arşivinde bulunur. `.github/workflows/build-android.yml` GitHub Actions ile Android APK dosyasını derlemek için arşivi açar.

**Not:** Şu an yerel ses dosyalarını çalmak için geliştirilmiştir; resmi Spotify kataloğunu uygulama içinde çalmaz.

APK: **Actions → Build Android APK → Artifacts → resonance-android-debug-apk**.
